## 🚀 Featured Projects:

### 🛡️ SentinelML — Machine Learning & Anomaly Detection

A server telemetry anomaly detection and early warning system designed to identify unusual system behavior and provide preventative warnings.

**Tech:** Python, Scikit-Learn, Isolation Forest, Pandas, NumPy, Matplotlib

**Focus:** Unsupervised anomaly detection, telemetry analysis, data processing, and early-warning systems.

### 📦 ShahEDA — Open-Source EDA Library

An automated Exploratory Data Analysis library built to simplify the early stages of dataset analysis.

**Tech:** Python, Pandas, NumPy, Jinja2, HTML

**Focus:** Automated data analysis, statistics, missing-value analysis, duplicate detection, visualization, and developer-friendly workflows.

Installable through:

```bash
pip install ShahEDA
```

### 👁️ AI Image Enhancer — Computer Vision & AI

An AI-powered image enhancement pipeline combining image processing techniques and deep learning-based super-resolution to improve image quality.

**Tech:** Python, OpenCV, PIL, TensorFlow, Deep Learning, Super-Resolution, Docker, Streamlit

**Focus:** Image preprocessing, enhancement, super-resolution, post-processing, and deployable AI workflows.
